# App Flow Navigation & User Journey

**Project Name:** DuskyMoon Productions Official Website  
**Version:** 1.0.0  

## 1. Global Navigation Structure
The website will utilize a minimalist, sticky navigation bar to ensure seamless access to core sections from anywhere on the site.

### 1.1. Top Navigation Bar (Header)
* **Logo:** DuskyMoon Productions Logo (Clickable -> routes to `/` Home).
* **Links:** 
    * `Artists` -> Routes to `/roster`
    * `Releases` -> Routes to `/releases`
    * `Demo Drop` -> Routes to `/contact`
* **CTA Button:** `Listen Now` (Links to the label's main Spotify playlist or latest release).

### 1.2. Global Footer (Critical for SEO)
* **Copyright Info:** `© 2026 DuskyMoon Productions`
* **Social Links:** Instagram, YouTube, Spotify label page.
* **The "Anchor" Link:** `Founded by Kxrn` (Hyperlinked with `dofollow` to `https://kxrn.is-a.dev` for Knowledge Graph entity authority).

## 2. User Journeys (Pathways)

### Journey A: The Fan / Listener
**Goal:** Discover new music and find streaming links.
1. **Entry:** Lands on Home (`/`).
2. **Action 1:** Sees the Hero section featuring the latest release ("Sapne").
3. **Action 2:** Clicks the `Stream Now` CTA on the hero banner.
4. **Resolution:** Redirects to a smart link page (e.g., Feature.fm) or directly to Spotify/Apple Music.
5. **Alternative Path:** Scrolls down Home, clicks `Releases` -> browses the grid -> clicks a specific album art -> finds streaming links for that specific track.

### Journey B: The Independent Artist
**Goal:** Submit a demo track to the label.
1. **Entry:** Lands on Home (`/`) or navigates directly via social media link.
2. **Action 1:** Locates and clicks `Demo Drop` in the top navigation.
3. **Action 2:** Lands on the `/contact` page.
4. **Action 3:** Reads submission guidelines (e.g., "Submit unreleased, mastered tracks only. Private SoundCloud links preferred.").
5. **Action 4:** Fills out the form (Name, Email, Track Link, Message) and hits `Submit`.
6. **Resolution:** Receives a confirmation message ("Demo received. We will contact you if interested.").

### Journey C: The Industry Professional / Press
**Goal:** Research the label's founders and signed artists.
1. **Entry:** Lands on Home (`/`).
2. **Action 1:** Clicks `Artists` in the top navigation.
3. **Action 2:** Lands on the `/roster` page.
4. **Action 3:** Views the artist grid. Clicks on "Kxrn" or "Ankit".
5. **Resolution:** Expands the artist card to read the bio and access direct links to their individual Spotify profiles or personal websites.

### Journey D: The Search Engine Crawler (Googlebot)
**Goal:** Understand the entity relationship and index the site.
1. **Entry:** Lands on `sitemap.xml` or `/`.
2. **Action 1:** Parses the HTML `<head>`.
3. **Action 2:** Detects and ingests the JSON-LD `@type: RecordLabel` schema.
4. **Action 3:** Follows the internal links (`/roster`, `/releases`).
5. **Action 4:** Discovers the footer link to `https://kxrn.is-a.dev`.
6. **Resolution:** Updates the Google Knowledge Graph, associating "DuskyMoon Productions" as an organization founded by the entity "Kxrn".

## 3. Page-Level Navigation Flow

### 3.1. Home (`/`)
* **Section 1 (Hero):** Latest Release Spotlight + `Stream Now` CTA.
* **Section 2 (About Snippet):** Brief intro to the label's vision.
* **Section 3 (Featured Artists):** Mini-carousel of the roster -> `View All Artists` CTA.
* **Section 4 (Recent Releases):** Grid of the 3 most recent tracks -> `View Full Catalog` CTA.

### 3.2. Artist Roster (`/roster`)
* **Header:** "Our Artists"
* **Grid Layout:** Cards for each artist.
* **Interactivity:** Clicking a card reveals a modal or expands the section to show the bio, latest track, and social links.

### 3.3. Releases (`/releases`)
* **Header:** "Discography"
* **Filter (Optional):** Filter by year or artist.
* **Grid Layout:** Album covers with Track Title and Artist Name. Hover effect to reveal a "Play" icon linking to streaming platforms.

### 3.4. Contact & Demos (`/contact`)
* **Header:** "Get in Touch / Submit a Demo"
* **Form Layout:** Clean, minimalist input fields.
* **Socials:** Explicit links to the label's official social media channels.
